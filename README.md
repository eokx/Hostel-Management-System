# Hostel Management System

## Project Overview
The **Hostel Management System** is a Java-based mini project developed to simplify hostel management activities. It provides a basic application to manage student information, room allocation, and hostel records.

The project uses Java for application development and MySQL for database management.

## Technologies Used
- **Programming Language:** Java
- **IDE:** NetBeans 12.0
- **Database:** MySQL
- **Connectivity:** JDBC
- **GUI:** Java Swing / Forms

## Features
- Student Registration
- Student Record Management
- Hostel Room Management
- Room Allocation
- Database Connectivity
- View and Manage Student Details

## Project Structure
- `Source Packages` – Contains Java source code.
- `db` – Contains database connection code.
- `MySQL Database` – Stores student and hostel information.

## Database
The project uses MySQL to store and manage hostel-related information.

## How to Run
1. Download or clone this repository.
2. Open the project in NetBeans IDE.
3. Create the required database in MySQL.
4. Configure the database connection in `DBConnection.java`.
5. Add the MySQL JDBC Connector to the project libraries.
6. Run the main Java file.

## Project Purpose
This project was developed as part of an Academic Mini Project to understand Java programming, database connectivity, JDBC, and basic application development.
